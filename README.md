Hello World

Página HTML simples que exibe "Hello World" no navegador. Serve como projeto inicial para praticar o básico de HTML.

Pré-requisitos
Um navegador moderno (Chrome, Firefox, Edge ou Safari)
Git 2.x ou superior (opcional, apenas para clonar o repositório)
Python 3.8 ou superior (opcional, apenas para rodar um servidor local)
Instalação
Clone o repositório (ou baixe os arquivos manualmente):
bash
git clone https://github.com/seu-usuario/hello-world.git
Entre na pasta do projeto:
bash
cd hello-world
Exemplos de uso

Abrindo direto no navegador:

bash
# Linux
xdg-open index.html

# macOS
open index.html

Rodando com um servidor local:

bash
python3 -m http.server 8000

Depois acesse http://localhost:8000 no navegador. A página exibirá:

Hello World
